# Path & Pulse — Kyoto Travel Guide

A responsive travel guide landing page for Path & Pulse, with travel service links, a photo slider, travel tips, a newsletter signup form, a login demo, and a currency converter.

## View the site

Open `path-and-pulse-navigation-kyoto-guide.html` in a browser.

## Project files

- `path-and-pulse-navigation-kyoto-guide.html` — page content and layout
- `path-and-pulse-navigation-kyoto-guide.css` — page styles
- `path-and-pulse-navigation-kyoto-guide.js` — interactive features
- Image files — logo and travel photos used by the page

Keep these files together so the page can find its stylesheet, script, and images.

## Notes

The login and newsletter forms are demos; they do not store or send user information. The currency converter fetches exchange rates from the ExchangeRate-API service and needs an internet connection.

## Built with

HTML, CSS, and JavaScript
